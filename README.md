# Распознавание эмоций

Программа которая распознает, какие у тебя эмоции. Работает на сверточной модели(CNN)!

**Автор:** Архипов Дмитрий
**Год:** 2026

## Что это?

Тут два скрипта:
1. `train_model.py` - обучает нейросеть
2. `main.py` - распознает эмоции с камеры или с фотки

### Какие эмоции распознает:

- angry (злость)
- disgust (отвращение)
- fear (страх)
- happy (радость)
- neutral (нейтрально)
- sad (грусть)
- surprise (удивление)

## Что нужно

### Железо
- Комп с дискретной видеокартой
- Веб-камера
- 8+ ГБ оперативки

### Софт
- Python 3.8+
- CUDA если есть nvidia
- 
## Как использовать

### 1. Обучить модель

Базово:
```bash
python train_model.py
```
### 2. Распознать эмоцию

С вебки (интерактив):
```bash
python main.py
```

Жми **ПРОБЕЛ** чтоб сделать фотку, **ESC** чтоб выйти.

С файла:
```bash
python main.py -i фотка.jpg
```

Своя модель:
```bash
python main.py -m models/моя_модель.pth -i фото.jpg
```
Все картинки 48x48 пикселей, черно-белые.

МОДЕЛЬ BaseCNN
    │

    └─ Classifier (Полносвязные слои)
