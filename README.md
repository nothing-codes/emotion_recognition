# Распознавание эмоций

Программа которая распознает, какие у тебя эмоции. Работает на сверточной модели(CNN)!

**Автор:** Архипов Дмитрий
**Год:** 2026

## Что это?

Тут два скрипта:
1. `train_model.py` - обучает нейросеть
2. `main.py` - распознает эмоции с камеры или с фотки

### Какие эмоции распознает:

- angry (злость)
- disgust (отвращение)
- fear (страх)
- happy (радость)
- neutral (нейтрально)
- sad (грусть)
- surprise (удивление)

## Как использовать

### 1. Обучить модель

Базово:
```bash
python train_model.py
```
### 2. Распознать эмоцию

С вебки (интерактив):
```bash
python main.py
```

Жми **ПРОБЕЛ** чтоб сделать фотку, **ESC** чтоб выйти.

С файла:
```bash
python main.py -i фотка.jpg
```

Своя модель:
```bash
python main.py -m models/моя_модель.pth -i фото.jpg
```
Все картинки 48x48 пикселей, черно-белые.

## Что делает нейросеть

Сверточная сеть с 4 блоками:
- Блок 1: 1 → 64 канала
- Блок 2: 64 → 128
- Блок 3: 128 → 256  
- Блок 4: 256 → 512

Потом полносвязные слои и на выходе 7 классов эмоций.

Используется:
- Batch Normalization
- Dropout чтоб не переобучалась
- Аугментация данных (повороты, сдвиги и т.д)
